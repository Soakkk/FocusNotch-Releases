# FocusNotch para macOS

Canal oficial de instaladores y actualizaciones firmadas de FocusNotch. El código fuente se mantiene en un repositorio privado.

Los instaladores aparecerán en [Releases](https://github.com/Soakkk/FocusNotch-Releases/releases). Requieren macOS 14 Sonoma o posterior y son universales para Apple Silicon e Intel.

Desde la versión 2.1, FocusNotch puede buscar y descargar nuevas versiones desde la propia app. Los usuarios de 2.0 deben instalar 2.1 una vez manualmente para incorporar el actualizador.

Este repositorio contiene únicamente información de distribución, el catálogo de versiones y los instaladores. No contiene código fuente, claves privadas ni datos de sesiones.

Los archivos ZIP de código fuente que GitHub genera automáticamente no son el instalador. Descarga el archivo DMG de la versión que quieras instalar.
